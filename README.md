# ESP32 Temperature Monitoring System — DITA/XML Documentation

## Overview

This project demonstrates structured technical documentation for an ESP32-based temperature and humidity monitoring system using DITA and XML.

The documentation is organized using topic-based authoring principles, separating information into concept, task, and reference topics. A DITA map is used to organize the individual topics into a complete documentation set.

## Documentation Includes

- System overview
- Device installation instructions
- Wi-Fi configuration procedure
- Troubleshooting information

## Technologies and Documentation Skills

- XML
- DITA
- Markdown
- GitHub
- Structured Authoring
- Topic-Based Authoring
- Technical Documentation
